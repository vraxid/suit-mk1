# Suit Mk1

Blueprint viewer and build log for my Spider-Man suit build: 3D hologram views of the suit panels, faceshell, lenses, web shooters and logo molds, with task lists, a build log and a print queue.

Live: https://vraxid.github.io/suit-mk1/

- Progress is saved on each device (browser storage). Use **Export progress** / **Import progress** at the bottom of the page to copy it between devices.
- Works offline once opened (the music streams, so it needs a connection).
- `audio/music.mp3` opens with a 12 s startup sound; the intro is timed to it and the music loops from 12 s.
- When you change any file, bump `VERSION` in `sw.js` so installed copies pick up the update.
